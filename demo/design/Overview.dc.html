BORG//CONSOLE
operator frontend — design exploration 01
Frontend design for the Borg cognitive-memory harness. Five screens against the demo server's REST + WebSocket contract (demo/server/src/app.ts, live.ts). Static mock — all data illustrative, interactions simulated; wiring notes in design/CONTRACT-NOTES.md.
Screens
01 / CHATFLAGSHIP
Operator chat + active sessions. Cognition panel: radial mind core (3 variants) showing phase ring, token flow, system_1/system_2, recalled evidence, and honest terminal outcomes — including deliberate silence as a first-class artifact in the thread.
02 / MIND
Live internals: identity (values, goals, traits, open questions), creator-directives vs commitments as two distinct ledgers, 8 memory bands, belief graph with contradicted/superseded edges. Two page layout variants.
03 / REVIEWS
Issue-resolution dashboard. Per-kind actions: keep-both / supersede-with-winner / invalidate / dismiss / accept / reject; creator-directive reconciliation gets its own survivor-picker flow. Three resolution-card variants.
04 / DREAM
Offline-phase control: pick from the 13 processes, plan → apply two-step, live run feed, dream reports with errors, audit trail with revert.
05 / SETTINGS
Prompt block editor with override/reset-to-default and assembled-framing preview; runtime + scheduler config; creator entity; reset with confirm token.
06 / ACTIVITY
What the entity did today, without asking it: day-grouped journal of every turn — autonomous wakes with trigger provenance, phase breakdowns, deliberate silences, the private train-of-thought lane, wake budget, and cancellable self-scheduled wakes.
Design system
Brutalist terminal. JetBrains Mono throughout, 1px hairline panels, zero border radius, warm near-black ground (#0B0B09), no decoration that isn't data.
Mood is the only color. A single accent hue derived from current mood (valence → hue, arousal → intensity) tints the whole app: nav, live indicators, the mind core. Errors keep a fixed red so failure never masquerades as feeling.
Neutral language. The UI says "the entity" / "agent", never a persona.
Honesty rules (from the contract)
A turn can end emitted / observed / suppressed / silent / failed — the animation and the thread render all five distinctly; silence is a deliberate outcome, not an absence.
Deliberation path (system_1 fast vs system_2) changes the core's behavior, not just a badge.
Recalled memories shown per-band as evidence drawn into the core during retrieval, from evidence_ledger:built.
